# 仓储会员来源约定

目录、适用范围和详情分别位于 `/catalog`、`/scope` 与 `/detail`，对应浏览器页面以 `.html` 结尾。三者是可以独立改变的观察来源，详情与适用范围使用目录中的稳定标识，不用显示名称做业务键。

- edition 为 1 或 2，表示两个发布期；同一活动同一发布期的三类观察组成一次发布（publication）。
- `blank=catalog|scope|rule` 模拟临时页面空白，返回 `{"blank": true}` 或带 `data-blank` 的空页面；`fault=1` 模拟来源故障（HTTP 500）。两者都是"暂时读不到"，不代表活动取消或无优惠。
- 目录条目带 `level`（会员等级）与 `benefit`（优惠类型，如满额返券、折扣）；适用范围带 `stores` 与 `levels`；规则正文 `detail` 是对外解释原文。
- 来源只监听环回地址，没有真实人员、订单或账号。
